The audit checked Python imports, declared requirements, source headers, README citations and bundled images. Package metadata was inspected in the tested environment on 2026-10-09. No externally attributed copied Python implementation was identified. A source audit cannot establish ownership of unattributed material.

Dependency attribution and other obligations still apply when redistributing dependency source or binaries. Installed wheels can include additional components and notices; preserve their complete upstream license files when packaging an environment. This repository's LICENSE does not replace those files. ## Figures and citations

`images/givens-rotation-matrix-construction.png` originally reproduced artwork attributed to the Stanford Exploration Project. Its reuse license was not established. The current file is an original rendering of the standard mathematical matrix, generated by `scripts/draw_givens_matrix.py`. The original pixels are not included in the current tree. Earlier Git revisions containing the Stanford artwork are outside the 0BSD grant. The historical manuscript retains a citation for the mathematical background.

Other bundled figures are presented by the original repository as project outputs. Their provenance was not independently reconstructed from every historical run. Citations acknowledge scientific sources; they do not grant rights to republish those papers or their figures.
